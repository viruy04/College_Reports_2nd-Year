### 4. МДК.02.01 Технология разработки программного обеспечения
**Цикл дисциплины:** профессиональный  
**Часы:** 60  
**Формы обучения:** лекции, лабораторные работы, проектная деятельность, самостоятельная работа  
**Форма контроля:** текущий контроль успеваемости, промежуточная аттестация (дифференцированный зачёт, 3–4 семестры)  
**Язык обучения:** русский  

**Цели освоения дисциплины:**  
- Освоение полного цикла разработки программного продукта: от анализа требований до сдачи готового решения.  
- Формирование навыков проектирования программных систем с использованием стандартов и методологий (UML, IDEF0, DFD).  
- Приобретение опыта разработки технической документации: техническое задание, пользовательские истории, диаграммы, тест-кейсы.  
- Освоение инструментов командной разработки, контроля версий, тестирования и ревью кода.  
- Разработка законченного приложения с графическим интерфейсом на C# (WPF) в рамках учебного проекта.  

**Основные знания:**  
- Методологии разработки программного обеспечения: водопадная, итерационная, Agile (User Story, Use Case).  
- Стандарты оформления технической документации (ГОСТ, ТЗ).  
- Язык моделирования UML: диаграммы классов, последовательности, деятельности, состояний, компонентов, развёртывания.  
- Функциональное моделирование: DFD, IDEF0.  
- Принципы тестирования ПО: виды тестов, написание тест-кейсов, модульное тестирование.  
- Основы код-ревью и стандарты кодирования на C#.  
- Работа в команде: распределение задач, планирование (диаграмма Ганта), координация модулей.  
- Разработка WPF-приложений: архитектура MVVM, привязка данных, стили, анимации.  

**Ключевые умения:**  
- Анализ предметной области и формулировка требований к программному обеспечению.  
- Разработка технического задания и пользовательских сценариев.  
- Создание комплекта UML-диаграмм для проектирования системы.  
- Построение функциональных моделей (DFD, IDEF0).  
- Разработка модульного кода на C# с соблюдением принципов ООП.  
- Реализация графического интерфейса в WPF с использованием стилей, триггеров и анимаций.  
- Проведение модульного тестирования и обработка исключений.  
- Выполнение инспекции кода и ревью в соответствии со стандартами.  
- Организация командной работы над проектом: планирование, интеграция модулей, документирование.  
- Создание завершённого приложения с визуализацией физических процессов (моделирование электрических цепей).
